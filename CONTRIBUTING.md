# Contributing

External criticism, reproduction attempts and failed tests are welcome.

## Good contributions

- application runtime logs;
- reproducible fixtures;
- checksums;
- save-roundtrip comparisons;
- platform/version reports;
- deterministic counterexamples;
- documentation corrections;
- licence/provenance findings.

## Validation reports should include

- application and version;
- operating system;
- ATLAS Clarus integration/package version;
- Workflow version;
- master SHA-256;
- exact input representation;
- expected and observed `atlas_row_id`;
- expected and observed master RGB / HEX;
- output file where relevant;
- output SHA-256;
- whether the test involved physical measurement.

## Claim discipline

Please distinguish:

- software/runtime behaviour;
- digital colour analysis;
- profile-dependent production feasibility;
- real DEVICE values;
- physical measured QC.

A digital result is not a measured print result.

## Experimental work

Source Authority extensions remain experimental unless explicitly promoted.

If source authority is unresolved, document the conflict rather than selecting whichever route produces the most convenient numerical result.
