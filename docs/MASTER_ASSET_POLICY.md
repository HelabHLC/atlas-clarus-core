# Master Asset Policy

The authoritative master is supplied externally and must not be committed to this repository by default.

## Frozen contract

- Canonical filename: `atlas_master__active_master__v2_illumext.pkl`
- SHA-256: `8283ab91b10f89ac758d09ecf5fb4d6343536600a06dd468b1cc1ecf4ec747c4`
- Rows: `13,283`
- DataFrame index: `RangeIndex(0, 13283)`, used as `atlas_row_id`

The byte hash must be verified before deserialisation. A different hash is a different artifact and must never be silently accepted as the normative master.

Derived runtime files may accelerate execution, but they are not independent colour authorities and must retain an explicit binding to this frozen contract.
